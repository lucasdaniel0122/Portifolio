API - Kernel Panic

Criação de um site com resultados de exportação e importação dos municípios e estados de São Paulo, onde nele temos dois tipos de gráficos para consulta (funil e linha), tendo diversos filtros em ambos para análises mais específicas, sendo elas: valor FOB, valor agregado, código NCM, filtros por ano de exportação e importação, filtros por meses de produtos exportados e importados, dentre outros.

Atuei na equipe como parte de time de desenvolvedores (Dev. Team), onde criei o banco de dados do projeto para alocação dos dados presentes no arquivo .csv, disponibilizados em dados abertos no próprio site governamental de Estatísticas Comerciais em Dados abertos e, onde também criei as jQuery para filtros de ambos os gráficos presentes no site (funil e linha). Tudo utilizando MySQL para desenvolvimento das tabelas e jQuery, e brModelo para modelo lógico relacional. Foi usado como uma alternativa mais leve para carregamento dos filtros o Google Cloud, onde utilizei BigQuery, que suporta bancos mais pesados, facilitando a criação das jQuery e também otimizando os dados e seu carregamento demorado.

Tecnologias utilizadas: Flask, Python para tratamento de dados, HTML5, CSS3, Java Script para estrutura do projeto, CSS3 para seu layout agradável, Java Script para funções de carregamento e funcionalidades da página como click em botões para abrir outras páginas, efeito de rolagem e etc, MySQL para o database, tabelas e jQuery dos filtros dos gráficos, brModelo para geração do modelo lógico relacional, Charts.js para os gráficos de funil e linha, Figma para design das páginas.

Doces-App

Desenvolvimento de uma plataforma web de controle financeiro e gestão de vendas, especialmente desenvolvida para empreendedores doceiros. O sistema oferece uma solução completa e intuitiva para rastrear receitas, despesas, lucros, vendas diárias, ajudando donos de docerias a otimizar operações, reduzir perdas e maximizar ganhos. Com um painel simples onde poderá ser registrado vendas de bolos, doces e encomendas personalizadas, gera relatórios automáticos e prevê tendências de negócio - tudo em tempo real, acessível de qualquer dispositivo. Com essa ferramenta, empreendedores transformam dados em decisões inteligentes impulsionando o crescimento de seus negócios, garantindo sustentabilidade financeira em um mercado competitivo. (Em andamento!!)

Para construir um sistema robusto e moderno, como Desenvovlvedor Full Stack, devo garantir diversificação de tecnologias, garantindo performance, segurança e facilidade de manutenção.

Font-end: HTML e CSS para estrutura e estilização responsiva, criando layouts atrativos e adaptáveis; JavaScript para interatividade dinâmica, como validações de formulários e atualizações em tempo real.

Back-end: Python com Flask para o servidor web, gerenciando lógica de negócio e APIs; Node.js para tarefas assíncronas e integração de serviços externos. Além de Banco de Dados para armazenamento estruturado de dados financeiros, vendas e usuários, assegurando consultas rápidas e relatórios precisos.

Ferramentas de Desenvolvimento: VSCode como editor principal para codificação eficiente; GitHub para controle de versão, colaboração e hospedagem do repositório, facilitando revisões e deploy contínuo.

Participação como Dev Full Stack: Como desenvolvedor full stack, liderei todo o ciclo de vida do projeto, desde a concepção até o deploy. No front-end, projetei interfaces intuitivas e responsivas, garantindo uma experiência de usuário excepcional para empreendedores ocupados. No back-end, implementei a lógica de negócio, conectei o banco de dados e desenvolvi APIs seguras, assegurando que dados sensíveis fossem protegidos. Colaborei em testes, otimização de performance e integração de tecnologias, resultando em um produto funcional e escalável. Esse projeto demonstrou minha capacidade de entregar soluções end-to-end, transformando ideias em ferramentas práticas que geram impacto real no mundo dos negócios.

Stranger Things - DevArt

Desenvolvimento web de um site já existente de uma série de ficção/fantasia chamada "Stanger Things" da empresa de streaming "Netflix" a qual se tornou um grande sucesso entre os jovens da geração Z. As produtoras da série em parceira a Netflix fizeram um website o qual era bastante antigo, então, na intenção de ser um projeto totalmente autônomo, peguei o site antiho e reformulei para os dias atuais, dando mais estilizações com base nas tecnologias avançadas dos tempos mais modernos, mas, ainda sim, mantendo a essência que a série passa originalmente, com efeitos e estilizações com efeito Parallax e textos infinitos passando pelo site, além de outras animações ao longo do novo website desenvolvido.

Na construção desta Landding-Page, como Dev. Full Stack, utilizei as tecnologias bases de Front-End, como HTML, CSS, Java Script e GSAP. Onde no HTML é presente toda sua parte estrutural das seções (Hero, Cidades, Depoimentos, Agradecimentos e Rodapé). No CSS, temos toda a estilização do site, com cores partidas do vermelho e com alguns subotns do mesmo na sua tonalidade mais escura, dando um ar mais "sombrio" ao site, e, também seguindo a proposta da série. Além de algumas animações com "@keyframes", como, o texto infinito presente no rodapé. Já o Java Script foi feito o efeito Parallax presente na Hero do site e as vinculações para animação com GSAP, que são os efeitos de "blur" das seções "Cidades e Agradecimentos".

Seu layout foi desenvolvido totalmente pelo app Figma, e, o desenvolvimento completo foi feito pelo Visual Studio Code. O projeto está diretamente alocado no Github e na Vercel, sendo toalmente público e acessível a todos.
